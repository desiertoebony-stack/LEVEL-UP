# Kids Playhouse — One-page website

A responsive, one-page kids playhouse website built with plain HTML, CSS, and JavaScript. No build step, framework, or package installation is required.

## Preview locally

1. Download or extract this folder.
2. Open `index.html` in a modern browser.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, `script.js`, and this `README.md` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under the build/deployment source, choose **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site.

## Customize before publishing

Update these sample details in `index.html`:
- Attraction names/descriptions to match your actual playhouse.
- Opening hours (currently sample hours: daily, 9:00 AM–8:00 PM).
- Promotional rates (currently sample prices: ₱149, ₱249, and ₱399).
- Address and phone/social contact placeholders.
- Any age limits, socks policy, re-entry rules, or holiday schedules.

The Google Fonts import in `styles.css` is optional. The site still works if external font loading is unavailable.

## Inquiry form

The form runs in the browser and prepares a message that visitors can copy. It does **not** submit bookings or send data to a server. Connect it to your preferred booking/contact service if you want to receive inquiries automatically.
